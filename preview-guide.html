Option Lens: ETH-only preview guide

This guide describes the separate, no-login, ETH-only Chrome extension candidate. It is not a public installation invitation, a download link, or proof of Chrome Web Store approval. External tester access remains blocked pending market-data, legal and publisher reviews.

Important distinction: the original development extension needs an optional local account service for simulated Pro; this preview does not. Do not load the original apps/options-overlay directory when following these ETH-only instructions. It contains a localhost API permission and sign-in controls absent from this candidate.

What this preview actually does

It adds a small read-only panel on supported https://www.binance.com/*eoptions* pages showing up to six ETH option contracts from one expiry. Data include Binance-supplied mark IV, bid/ask IV, delta, an ETH index reference and median mark IV. It only requests three public EAPI endpoints. No Binance login, trading keys, order placement, BTC access, customer account, subscription or paid feature.

Exchange and index times are checked, but individual mark quotes do not have timestamps. Figures are indicative; check exchange information independently. Local regulations and provider terms may restrict availability. Option Lens is independent of Binance and Google.

Developer-controlled local install (not for external distribution)

  1. Use only the authorized private repository or a vetted candidate from the operator. Do not download unverified extensions advertised by third parties.
  2. From the repository root, run npm ci, then npm run test -w @saas/options-overlay and npm run package:optionlens:free.
  3. The exact unpacked preview is under apps/options-overlay/dist/eth-preview/unpacked. Verify it contains manifest.json and the four preview icons. It must have empty permissions and only https://eapi.binance.com/* in host_permissions.
  4. In desktop Chrome, open chrome://extensions, enable Developer mode and select Load unpacked. Choose the unpacked preview folder, not the ZIP file or original development extension directory. Do not circumvent browser security warnings.
  5. Open a supported Binance ETH E-options page and reload the tab if needed. Observe ETH only, at most six rows and one expiry; Refresh requests a new snapshot. If Binance does not serve the page in your region, stop rather than bypassing location controls.
  6. To stop requests, disable or remove the extension in Chrome. It has no Nakamoto Studio account to delete; Binance and your browser may retain separate request metadata.

Chrome Stable unpacked installation and multi-locale behavior need final confirmation on the exact candidate before external testers are invited. No public download or Chrome Web Store listing currently exists.

Email studionakamoto@gmail.com for non-sensitive feedback or the support and deletion process. This page is not an invitation to share secrets or payment information.

Known limitations

ETH only; one expiry; six rows; not continuous live streaming; short-lived caching for automatic requests; no per-mark timestamp; no history, forecasts, personalized strategies, Binance account integration, trades, BTC or Pro in this preview. If the API is stale, blocked, malformed or unavailable, the panel should say the data are unavailable rather than showing invented figures.

Review the current privacy draft and terms draft. Both include facts about the separate local Pro prototype and require final legal review for a public beta.
