An experimental research overlay, not a trading service.

The following is product-specific draft language for controlled local evaluation only. These are not finalized terms for a hosted beta or commercial subscription; legal review and a confirmed operating entity are required before public distribution.

Not a public commercial offer

1. Product and availability

Option Lens is a Chrome Manifest V3 read-only extension prototype under the Nakamoto Studio working brand. It overlays public options analytics on supported Binance E-options pages. It may stop working if the exchange API, browser platform, page layout or available data changes. There is no uptime, continued-availability or compatibility commitment for this development build.

2. No financial advice or executable quotes

Mark IV, bid/ask IV, delta, index, approximate at-the-money IV and normalized term-slope summaries are provided for informational research only. They are not investment advice, individualized guidance, trading signals, quotes you can execute, predictions of returns or guarantees of correctness. Public Binance mark responses have no per-quote freshness timestamps; data can be delayed, stale, absent or wrong. Verify independent primary data and consider financial risk before making decisions. This extension never places orders and is not a broker or custodian.

3. Free and test-only Pro

The Free local build shows limited ETH research fields without login. Pro features exist only for a locally validated test entitlement; an operator-created account alone does not activate them. There is no public subscription, verified self-service registration, checkout, price, recurring charge, cancellation portal or refund offering. Future paid terms would need clear pricing, renewals, taxes, cancellation and refund procedures before any payment is accepted. If entitlement checks fail, the interface may fall back to Free.

5. Privacy, security and accounts

Do not enter exchange trading credentials or payment card details into Option Lens. The optional development account API is bound to local loopback HTTP and is not a hosted production service. See Privacy for extension storage, public API requests and optional test account handling. Sign out from the popup and uninstall in Chrome to end local use. Removing the extension does not automatically erase a separate locally operated subscriber account; see deletion requests.
