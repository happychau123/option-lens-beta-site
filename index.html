Options volatility, in context.

A read-only Chrome overlay for reviewing implied volatility (IV), bid/ask IV, delta and expiry patterns beside supported Binance E-options pages. Compare research signals without opening an order ticket through the extension.

Source access is currently invitation-only. Request developer preview access by email; there is no Chrome Web Store listing, downloadable extension, public sign-up, hosted account service or live paid plan.

Not a public launch. The primary development extension is an unpacked prototype whose subscriber API points to http://127.0.0.1:3212. A separate ETH-only preview candidate has been built with no account service, but is not publicly distributed; neither is a published production extension. A beta tester cannot get remote Pro access just by installing the package. Public distribution, publisher verification and any payment flow remain blocked.

The research workflow

Purpose-built to inspect, not execute

Option Lens fetches public options-market data through its extension service worker. It does not require exchange API keys, place orders, or read your trading history.

01 · Observe

Read mark IV & Greeks

See Binance-provided mark, bid/ask IV and delta for selected rows, with an ETH index reference and source timestamp where available.

02 · Compare

Across expiry dates

Review a median mark-IV summary for an expiry. The simulated Pro tier adds approximate at-the-money (ATM) IV and normalized 30-day term slope.

03 · Verify

Know the limits

Index and exchange timestamps are checked, but individual mark quotes have no freshness timestamps. Missing, stale or inaccurate values remain possible.

Developer onboarding · local only

Try the Free ETH view from source

These instructions apply only to developers who have been explicitly granted access to the private source repository. They are not a public download or Chrome Web Store installation process. Chrome and Node.js 22+ are required.

Validate the checkout

In the repository root, run npm install, then npm run test -w @saas/options-overlay and npm run build -w @saas/options-overlay.

Load the extension

Open chrome://extensions, enable Developer mode, choose Load unpacked, and select apps/options-overlay. Reload the Binance tab after installing.

Open the supported page

Visit a Binance E-options page such as the /en/eoptions route on https://www.binance.com. Choose ETH, refresh for a new snapshot and check timestamps against the exchange.

Free does not need local sign-in. The popup's sign-in form is for an optional, separately running loopback API with an operator-created test account; sign-in alone does not grant Pro. See setup help if the panel is absent.

Frequently asked questions

Before using Option Lens

Can I download Option Lens from the Chrome Web Store?

No. The current build is not approved, listed or distributed publicly. Local testing from the private repository is available only to invited developers; request access through the support email.

Do I need a Binance login or API key?

No. The extension requests public market information from Binance. Do not give it passwords, API keys or trading credentials. Availability of the Binance page and market data depends on the provider and your region.

Are the IV numbers tradable, real-time or predictive?

No. They are indicative analytics, not executable prices or forecasts. The public mark endpoint does not supply per-row quote timestamps; independently verify any values before making a financial decision.

How does Pro work during the beta?

Pro is a simulated development entitlement controlled by a locally operated account API. There is no verified public registration, checkout, subscription price or remote access. An offline or expired entitlement falls back to Free.

Does uninstalling erase my information?

Removing the extension clears its on-device extension data. It does not delete a separate operator-created backend account. See the privacy and deletion steps.

Is Option Lens affiliated with Binance or Chrome?

No. Option Lens is an independent Nakamoto Studio prototype, not endorsed or approved by Binance or Google. Follow provider terms and local laws.
