Option Lens — ETH Preview: privacy policy

This policy describes only the separately packaged, read-only Option Lens ETH Preview Chrome extension version 0.1.0, published by Nakamoto Studio. The extension is an unpublished Chrome Web Store draft, not a currently available public release. The separate account-enabled ETH/BTC development prototype is not covered by this version-specific policy.

Publisher and privacy contact

Nakamoto Studio is the Chrome Web Store publisher of Option Lens — ETH Preview. For privacy questions, support, or a request concerning information voluntarily sent to support, email studionakamoto@gmail.com. Do not email Binance credentials, financial-account details, identity documents, or other secrets.

Single purpose and website access

The extension displays a read-only overlay with public ETH options implied volatility (mark, bid and ask), delta, a derived median IV for one expiry, and an ETH index reference next to supported https://www.binance.com/…/eoptions pages. It uses a narrowly scoped content script to check the current Binance URL path, insert its own panel, respond to the panel's Refresh and collapse buttons, and render received data. It checks for its own existing panel to avoid duplicate insertion.

It does not read order tickets, account balances, exchange cookies, usernames, wallet details, API keys, or messages on the Binance page. It does not collect general browsing history, monitor activity on unrelated websites, or place orders.

What the ETH Preview does not collect

Version 0.1.0 contains no login, user account, password processing, payment or subscription functionality, personal analytics, advertising SDK, telemetry, location tracking, cross-site profiling, browser storage permission, or remote executable code. It does not transmit website content, browsing history or financial-account data to a publisher-operated service. Public options price and Greeks figures are market data, not information about your personal portfolio.

The Chrome browser, Google Chrome Web Store, Binance, your operating system, and internet service providers have independent data practices. This policy does not claim to control their logs, browser telemetry, account information, or site behavior.

Your choices, deletion and security

You can disable or uninstall the extension in chrome://extensions to stop the overlay and future API requests. Uninstalling ends its temporary in-memory state. This version does not create a Nakamoto Studio subscriber account or database record, so there is no extension-side account to delete. Email the contact above about support correspondence if you seek access, correction, or deletion; requests are handled subject to applicable legal requirements and provider retention obligations.

Market-data requests use HTTPS. No secret account credentials are required or requested by this version. API responses are treated as data, never evaluated as executable scripts.

Use limitations and policy changes

This extension uses information solely to provide its disclosed ETH options research overlay. It does not sell user data, transfer it for advertising, use it for creditworthiness or lending decisions, or use it for an unrelated purpose. Use of information received from Chrome APIs will adhere to the Chrome Web Store User Data Policy, including its Limited Use requirements.

Any future account-enabled or paid product, new third-party integration, analytics collection, or material change to the data practices requires an updated notice and extension review before distribution. This page covers the specific ETH Preview v0.1.0 package only and does not provide permission to use or redistribute Binance market data. See our support page and separate development-prototype privacy notice.
